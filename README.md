# StarWarsPong

Un clásico juego de Pong con temática de Star Wars. ¡Que la Fuerza te acompañe en esta épica batalla intergaláctica!

## Cómo Jugar

- **Jugador 1 (Izquierda)**: Usa las teclas **W** (arriba) y **S** (abajo)
- **Jugador 2 (Derecha)**: Usa las teclas **↑** (arriba) y **↓** (abajo)
- El primero en llegar a **7 puntos** gana la partida.

## Características

- Tema inmersivo de Star Wars (naves, láseres y sonidos épicos)
- Gráficos retro con estilo pixel-art
- Sonidos originales de la saga
- Modo multijugador local (2 jugadores)
- Dificultad progresiva

## Tecnologías Utilizadas

- **Lenguaje**: Java
- **Biblioteca gráfica**: Processing / Java2D
- **Sonidos**: Archivos de la saga Star Wars

## Cómo Ejecutar

1. Abrí el proyecto en Eclipse o IntelliJ IDEA
2. Ejecutá la clase principal (`Main` o `StarWarsPong`)
3. ¡Que comience el duelo!
